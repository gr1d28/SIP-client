# SIP-телефон с веб-интерфейсом

Сигнальный SIP-softphone (без передачи звука) на Go с использованием библиотеки
[emiago/sipgo](https://github.com/emiago/sipgo) и `net/http`. Веб-интерфейс:
регистрация на SIP-сервере, вызов на номер, отмена вызова, ответ/отклонение
входящего вызова, завершение разговора.

## Запуск (одной командой)

```bash
docker-compose up -d --build
```

(или `docker compose up -d --build`)

Веб-интерфейс: **http://localhost:8212**

Используются порты хоста (в compose включён `network_mode: host`):

- `UDP 5060` — SIP-сигнализация (нужен для входящих вызовов);
- `TCP 8212` — веб-интерфейс.

## Использование

1. В блоке **Регистрация** укажите адрес SIP-сервера (хост или `хост:порт`),
   номер (SIP-пользователя) и пароль → «Зарегистрировать». Статус — в блоке
   «Статус» (регистрация обновляется автоматически до истечения `Expires`).
2. **Вызов**: введите номер → «Позвонить». До ответа собеседника доступна
   кнопка «Отменить вызов» (CANCEL).
3. **Входящий вызов**: кнопки «Ответить» (200 OK) и «Отклонить» (603 Decline).
4. **Разговор**: кнопка «Положить трубку» отправляет BYE. Если кладёт трубку
   собеседник (BYE приходит от него), звонок завершается сам.
5. «Снять с регистрации» — REGISTER с `Expires: 0`.

Медиа не передаётся: обмениваются только SIP-сообщениями, SDP/RTP не
используются. Одновременно обслуживается один вызов.

## Логи

Логи пишутся в stderr, у контейнера их смотрят так:

```bash
docker logs -f sipphone
```

Полная трассировка SIP-сообщений — переменная окружения `SIP_DEBUG=1`
(проброшена в `docker-compose.yml`):

```bash
SIP_DEBUG=1 docker-compose up -d
```

## Параметры запуска

| Флаг    | По умолчанию    | Назначение                                                        |
|---------|-----------------|-------------------------------------------------------------------|
| `-web`  | `:8212`         | адрес веб-интерфейса                                              |
| `-sip`  | `0.0.0.0:5060`  | UDP-адрес SIP-транспорта                                          |
| `-ip`   | (авто)          | IP в заголовках Via/Contact; по умолчанию определяется по маршруту до SIP-сервера |

Если порт 5060 на хосте занят, укажите другой: в `docker-compose.yml`
раскомментируйте и задайте `command: ["-sip", "0.0.0.0:5062"]`
(для входящих вызовов SIP-сервер должен знать об этом порте).

## Запуск без Docker

Нужен Go ≥ 1.23:

```bash
go run .
```

## Структура проекта

- `main.go` — флаги, логгер (stderr), HTTP-сервер;
- `phone.go` — состояние телефона (регистрация/вызов), UDP-транспорт;
- `sip_register.go` — REGISTER с Digest-авторизацией и auto-refresh;
- `sip_call.go` — INVITE/ACK/CANCEL/BYE исходящие и входящие;
- `web.go`, `index.html` — API и интерфейс (port 8212).

## HTTP API

- `GET /api/status` — состояние регистрации и вызова (JSON);
- `POST /api/register` `{server, number, password}`;
- `POST /api/call` `{number}`;
- `POST /api/cancel`, `POST /api/answer`, `POST /api/decline`,
  `POST /api/hangup`, `POST /api/unregister`.
